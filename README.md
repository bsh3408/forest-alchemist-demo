# 숲속 연금술사 · 사용법

숲과 광산에서 재료를 모으고, 손님이 주문한 용액과 금속을 만들어 파는 **통합과학 학습 게임**입니다.
산·염기, 중화 반응, 산화·환원과 전자 이동을 게임 안에서 직접 다뤄 보고, 마지막에는 이온 수와 혼합 비율을 추론하는 문제로 마무리합니다.

**바로 하기:** https://bsh3408.github.io/forest-alchemist-demo/

---

## 1. 준비물

| 항목 | 내용 |
|---|---|
| 기기 | 크롬북, 노트북, 데스크톱 권장. 태블릿과 휴대폰도 되지만 화면이 좁아 조작이 불편합니다. |
| 브라우저 | 크롬 또는 엣지 최신 버전 |
| 인터넷 | 처음 열 때 약 12MB를 내려받습니다. 한 반이 동시에 접속해도 괜찮습니다. |
| 계정 | 필요 없습니다. 회원가입이나 로그인이 없습니다. |
| 시간 | 처음부터 최종 시련까지 약 1시간(학생 속도에 따라 다름). 두 차시로 나눠도 됩니다. |
| 선수 학습 | 산·염기와 중화 반응, 산화·환원(전자 이동)을 배운 뒤에 하면 가장 좋습니다. |

---

## 2. 학생이 하는 순서

1. 주소를 열고 **‘연금술 여정 시작하기’** 를 누릅니다.
2. 공방 이름을 적고 주인공을 고른 뒤 시작합니다.
3. **오전: 탐사.** 숲과 광산을 돌아다니며 재료를 모읍니다. 처음 보는 시료는 조사해서 정체를 맞혀야 채집할 수 있습니다.
4. **오후: 영업.** 손님이 한 명씩 찾아옵니다. 주문을 받아 용액을 만들고, 숯으로 금속을 재련하고, 금속을 석출해 건넵니다.
5. **영업 종료.** 번 돈으로 도구를 사고 다음 날로 넘어갑니다. 이 과정을 반복합니다.
6. **6일차부터** 특별한 손님이 찾아옵니다. 의뢰 4개를 해결해 지도·렌즈·열쇠·인장을 모읍니다.
7. 네 물건을 모두 모으면 지도가 가리키는 숲속 **성소** 를 엽니다.
8. 성소의 **3가지 시련**(중화 반응 추론 문제 3개)을 모두 맞히면 완주 코드가 나옵니다.

### 조작법

| 동작 | 방법 |
|---|---|
| 이동 | 방향키 또는 W·A·S·D, 가고 싶은 칸을 클릭해도 됩니다. |
| 조사·채집·열기 | 대상 옆에서 Space 또는 대상 클릭 |
| 가방 보기 | E 또는 상단 ‘가방’ 버튼 |
| 창 닫기 | Esc 또는 창의 ✕ |

## 3. 수업에서 쓰는 순서 (선생님용)

1. **미리 해 보기:** 수업 전에 선생님이 직접 1~2일차까지 해 보면 학생 질문에 답하기 쉽습니다.
2. **주소 나눠 주기:** 칠판에 주소를 적거나 QR코드로 나눠 줍니다.
3. **처음 5분 안내:** “오전엔 탐사, 오후엔 영업, 행동력이 떨어지기 전에 돌아와야 한다”는 것만 알려 주면 됩니다. 나머지는 게임 안내가 이끕니다.
4. **진행 중 순회:** 막히는 곳은 주로 ① 처음 보는 시료 조사, ② 중화에 필요한 부피 계산, ③ 재련에서 산화·환원 판단입니다.
5. **마무리:** 완주 코드나 도달한 일차를 확인하고, 성소 문제 풀이 과정을 함께 이야기해 봅니다.

## 4. 주의할 점

- **진행은 그 브라우저에만 저장됩니다.** 다른 기기나 다른 브라우저에서 열면 처음부터 시작합니다. 같은 기기로 이어서 하게 해 주세요.
- **여러 학생이 한 기기를 번갈아 쓰면 진행이 섞입니다.** 기기 하나에 기록 하나만 남기 때문입니다. 새 학생은 게임 안의 **‘새로 시작’** 을 누르면 처음부터 시작합니다. 앞 사람 기록은 사라집니다.
- **시크릿 창에서는 창을 닫으면 진행이 사라집니다.** 브라우저 기록을 지워도 사라집니다.
- **행동력이 0이 되면 강제로 상점에 돌아가고, 가진 돈을 모두 잃습니다.** 행동력을 보며 미리 귀환서(20C)로 돌아오게 해 주세요.
- **성소 시련은 틀리면 그날(게임 속 하루) 도전이 끝납니다.** 영업을 마치고 다음 게임 일차가 되면 새 문제로 다시 풀 수 있습니다. 실제로 하루를 기다릴 필요는 없습니다.
- **완주 코드(`DEMO-…`)는 체험용입니다.** 서버에 기록되지 않으며, 학생이 코드를 직접 보여 줘야 확인할 수 있습니다. 공식 평가 증명으로는 쓸 수 없습니다.
- 이 체험판에는 로그인, 이용 시간 제한, 창 이탈 감지가 없습니다. 수행평가처럼 엄격하게 운영하려면 별도 설정이 필요합니다.

## 5. 자주 묻는 질문

**Q. 처음부터 다시 하고 싶어요.**
게임 화면 오른쪽 위의 ‘새로 시작’을 누르면 1일차로 돌아갑니다.

**Q. 화면이 이상하거나 버튼이 안 눌려요.**
새로고침(F5)하고 ‘연금술 여정 시작하기’를 누르면 저장된 곳부터 이어집니다.

**Q. 우리 학교 버전으로 따로 쓰고 싶어요.**
이 저장소를 Fork한 뒤 Settings → Pages에서 `main` 브랜치를 켜면 나만의 주소가 생깁니다. 게임 파일은 모두 정적 HTML·JS라 별도 서버가 필요 없습니다.
